# claude-mods

Personal Claude Code mods, installable as a plugin marketplace.

| Mod | What it does |
| --- | --- |
| [session-activity-badge](session-activity-badge/) | Band above the prompt listing other working sessions with a task-list progress bar, their current work and their background tasks |

    claude plugin marketplace add RXL-SahilArora/claude-mods
    claude plugin install session-activity-badge@local-mods
